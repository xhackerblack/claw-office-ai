# 🤖 Claw Office AI — وكيل ذكاء اصطناعي لإدارة المكاتب

تطبيق ويب عربي بالكامل (يعمل أيضاً كـ PWA) لإدارة المكاتب بالذكاء الاصطناعي: معالجة المستندات (OCR)، إدارة العملاء والمهام، التحكم في مستخدمي بوت تلغرام، السجلات المباشرة، التقارير، والتدريب على القوالب.

**بدون أي تبعيات خارجية** — يعمل بـ Node.js فقط، لذلك يشتغل مباشرة على Termux.

---

## 📱 التشغيل على Termux (أسهل طريقة)

```bash
# 1) تثبيت Node.js (مرة واحدة فقط)
pkg update && pkg install nodejs git -y

# 2) تحميل المشروع
git clone https://github.com/xhackerblack/claw-office-ai.git
cd claw-office-ai

# 3) التشغيل
node server.js
```

ثم افتح المتصفح على هاتفك:

```
http://localhost:8080
```

> 💡 لتثبيته كتطبيق على الشاشة الرئيسية: من متصفح Chrome اختر **"إضافة إلى الشاشة الرئيسية"**.

> 🔁 لتغيير المنفذ: `PORT=3000 node server.js`

---

## 💻 التشغيل على الحاسوب

نفس الخطوات — تحتاج فقط Node.js 16 أو أحدث:

```bash
git clone https://github.com/xhackerblack/claw-office-ai.git
cd claw-office-ai
node server.js
```

## 🏗️ البنية

```
claw-office-ai/
├── server.js              # خادم Node.js (API + ملفات ثابتة) — بدون تبعيات
├── package.json
├── data.json              # قاعدة بيانات JSON (تُنشأ تلقائياً)
└── public/
    ├── index.html         # الواجهة العربية (RTL) — 11 شاشة
    ├── styles.css         # التصميم الداكن بالنيون السماوي
    ├── app.js             # منطق الواجهة
    └── manifest.webmanifest  # دعم PWA
```

## 🔌 واجهات API

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | `/api/stats` | إحصائيات لوحة التحكم |
| GET/POST | `/api/tasks` | المهام |
| GET/POST | `/api/clients` | العملاء |
| GET | `/api/users` | المستخدمون |
| POST | `/api/users/toggle-block` | حظر/إلغاء حظر |
| GET | `/api/logs` | السجلات |
| GET/POST | `/api/settings` | الإعدادات |
| POST | `/api/search` | البحث العميق |

## 🎨 نظام التصميم

- خلفية `#0D1117` • بطاقات `#161B22` • نيون سماوي `#00D4FF` • بنفسجي `#7C3AED`
- واجهة عربية RTL بالكامل، بطاقات بزوايا 16px، توهج نيون، حركات سلسة

## ⚙️ ملاحظات

- البيانات تُحفظ محلياً في `data.json` (تُنشأ تلقائياً عند أول تشغيل).
- مفاتيح API (Telegram, Groq, Cloudflare) تُدخل من شاشة الإعدادات داخل التطبيق.
- لا تشارك ملف `data.json` أو مفاتيحك علناً.
